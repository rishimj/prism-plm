Mechanistic interpretability · Protein language models

What does a protein language model actually know?

ESM-2 learned the grammar of life from 65 million protein sequences, with no textbook and no structures. PRISM-Bio opens it up: it finds the neurons that track real biology, measures how many concepts each neuron mixes, and steers the model toward the motifs it discovered.

01 How it works

Reading the mind of a model that reads proteins

A protein is a string of 20 amino-acid letters that folds into a molecular machine. Language models trained on these strings develop internal "neurons". PRISM-Bio asks what each neuron responds to, and whether we can use that knowledge to control the model.

1

Read thousands of proteins

2

Find what excites a neuron

Name it with biology

Test those proteins for over-represented Gene Ontology terms and protein families (hypergeometric, BH-FDR).

4

Steer the model

Turn a concept into a direction in activation space, inject it mid-network, and watch predictions change.

src/steering · SteeringVector, SteeringHook
Why it matters. Protein language models now help design enzymes, antibodies and drugs. If we can see which concepts they rely on, we can trust, debug and steer them, the same way interpretability research is making text models safer. Every number on this page comes from real runs of the code in this repository.

03 Emergent structure

It never saw a 3D structure. It learned one anyway.

For every layer we ask: can a simple linear read-out recover alpha-helices, beta-strands and membrane-spanning segments from the model's activations? Scores are measured on proteins held out from training, against experimentally determined annotations.

06 Activation steering

Turn a concept into a dial

A concept vector is the average activation of proteins that have a property minus those that do not. Adding it into layer 6 of ESM-2 pushes the model's reading of a protein toward that concept. Drag the slider and watch what the model now "wants" each residue to be.

07 Engineering

From GPU cluster to your browser

Heavy analyses run as batch jobs; their results ship as static data with this site. A small FastAPI service on Azure runs ESM-2 live so you can analyze and steer your own sequences.
