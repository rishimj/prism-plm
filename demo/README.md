# PRISM-Bio interactive demo

An interactive website that shows what PRISM-Bio finds inside the ESM-2 protein language model:

| Section | What it shows | Backed by |
|---|---|---|
| **Protein explorer** | Neuron activity painted on AlphaFold structures of KRAS, hemoglobin, GFP, p53 and more, next to UniProt annotations | per-residue ESM-2 35M activations |
| **Emergent structure** | Layer-by-layer linear probes and single neurons that decode helices, strands and membrane segments | held-out proteins with experimental annotations |
| **Neuron atlas** | All 5,760 neurons of ESM-2 35M with polysemanticity scores and GO / protein-family labels | `scripts/run_single_neuron.py` recipe + hypergeometric enrichment |
| **Scaling study** | Polysemanticity and label rates for ESM-2 8M, 35M, 150M and 650M | `scripts/run_neuron_batch.py` recipe |
| **Activation steering** | Concept vectors (zinc finger, P-loop, membrane, secreted) injected at layer 6 | `src/steering` (`SteeringVector`, `SteeringHook`, concept probability shift) |

The site is static (GitHub Pages) and fully works on precomputed data. When the optional live API
is reachable, visitors can also analyze and steer **their own sequences**.

```
demo/
├── pipeline/   # regenerates every number on the site from real model runs
├── backend/    # FastAPI service (ESM-2 35M on CPU) + tests
├── deploy/     # docker compose + Caddy (HTTPS) + Azure VM setup script
└── web/        # Vite + TypeScript + D3 + 3Dmol.js site
```

## 1. Publish the site (GitHub Pages)

1. Merge this branch into `main`.
2. In the repository: **Settings → Pages → Build and deployment → Source: GitHub Actions**.
3. The `Deploy demo site` workflow builds `demo/web` and publishes it on every push that touches
   the site (or run it manually from the Actions tab). The URL will be
   `https://rishimj.github.io/prism-plm/`.

Local preview:

```bash
cd demo/web
npm install
npm run dev            # http://localhost:5173
```

## 2. Run the live API on your Azure B2s VM (optional)

The API needs about 1 GB of RAM and answers most requests in 1 to 5 seconds on 2 vCPUs.

1. **Open ports**: in the Azure portal, VM → Networking → add inbound rules for TCP **80** and **443**.
2. **Give it a hostname**: VM → Overview → Public IP → Configuration → set a *DNS name label*,
   e.g. `prism-bio`, which gives `prism-bio.<region>.cloudapp.azure.com`. Caddy uses this name to
   obtain a free Let's Encrypt certificate (HTTPS is required because GitHub Pages is HTTPS).
3. **SSH in and run the setup script** (Ubuntu 22.04/24.04):

   ```bash
   curl -fsSL https://raw.githubusercontent.com/rishimj/prism-plm/main/demo/deploy/azure/setup_vm.sh \
     | API_DOMAIN=prism-bio.eastus.cloudapp.azure.com bash
   ```

   It installs Docker, adds swap, clones the repo, and starts `api` + `caddy` with
   `docker compose`. Check `https://<your-domain>/api/health`.
4. **Point the site at it**: repository **Settings → Secrets and variables → Actions → Variables →
   New variable** `DEMO_API_URL = https://prism-bio.eastus.cloudapp.azure.com`, then re-run the
   `Deploy demo site` workflow. The status pill in the site header turns green.

You can also try any API without rebuilding: `https://rishimj.github.io/prism-plm/?api=https://your-host`.

Already running other projects on the same VM behind nginx or Caddy? Skip the `caddy` service
(`docker compose up -d api`), publish port 8000 on localhost, and add a reverse-proxy route
for `/api/` to it.

Updating: `cd /opt/prism-plm && sudo git pull && cd demo/deploy && sudo docker compose up -d --build`.

### API

| Endpoint | Body | Returns |
|---|---|---|
| `GET /api/health` | | model info and available concepts |
| `POST /api/analyze` | `{"sequence": "MKT...", "layer": 6}` | per-residue neuron tracks, helix/strand/TM probe predictions, masked-marginal P(native), atlas fingerprint |
| `POST /api/steer` | `{"sequence": "MKT...", "concept": "zinc_finger", "strength": 1.5}` | steered predictions, concept score, per-layer drift, motif matches |

Guardrails: sequences up to 400 residues, 30 requests/min per IP, CORS restricted to the Pages
origin (`ALLOWED_ORIGINS`), one inference at a time, LRU response cache, non-root container.

```bash
# run the API locally
pip install torch --index-url https://download.pytorch.org/whl/cpu
pip install -r demo/backend/requirements.txt pytest httpx
uvicorn demo.backend.app.main:app --reload     # from the repository root
pytest demo/backend/tests -q
```

## 3. Rebuild the data (optional)

Everything in `demo/web/public/data` and `demo/backend/assets` is generated by
`demo/pipeline` from public data (SwissProt via Hugging Face, UniProt features, AlphaFold DB).
It runs on a CPU in about 1.5 hours (most of it the 650M scaling run):

```bash
pip install -r demo/pipeline/requirements.txt
bash demo/pipeline/run_all.sh
```

### Methods in brief

* **Atlas.** 3,000 randomly sampled SwissProt proteins (50 to 1,000 aa). For each neuron: mean-pooled
  activations, top-100 proteins, k-means (k = 5) in a PCA-64 space, polysemanticity =
  1 − mean cosine similarity between cluster centroids. Labels: one-sided hypergeometric test of GO
  terms and protein families against the 3,000-protein background, Benjamini-Hochberg FDR.
* **Probing.** ~450 proteins with PDB-derived secondary structure and ~220 with transmembrane
  annotations, 60 residues sampled per protein, logistic regression per layer, 80/20 split by protein.
  The "best single neuron" is chosen on training proteins and scored on test proteins.
* **Showcase neurons.** "Feature detectors" are the neurons with the highest AUROC for an annotated
  feature *within that protein*; they are selected post hoc and labelled as such. "Structure neurons"
  are chosen on independent proteins.
* **Steering.** Concept vector = mean layer-6 activation of 150 positive minus 150 negative proteins
  (motif match, or UniProt subcellular location). Strength is expressed relative to the average
  activation norm at the injection layer. The concept signature is the expected log-odds of the
  concept's amino-acid composition under the model's per-position predictions.
